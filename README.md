# 老地图图幅编目与地名对照台

面向古地图整理者和地方志研究者，将老地图按图幅编目，登记年代、比例尺、投影和扫描件，并建立古今地名对照及沿革线索。应用为纯前端单页程序，所有资料保存在浏览器本地。

## Docker 一键启动

```bash
cp .env.example .env && docker compose up -d --build
```

服务默认映射到宿主端口 `21805`。停止服务可执行：

```bash
docker compose down
```

## 数据存储说明

应用使用 IndexedDB 持久化数据，Dexie 数据库名为 `gboldmap-db`。业务对象仓库为 `sheets`、`scans`、`placePairs`、`histories`，提交机制仓库为 `commits`、`baselines`、`pendingConflicts`、`workspaces`：

- `version(1)` 建立首版索引结构，并在首次创建数据库时写入图幅、扫描件、地名对照和沿革种子数据。
- `version(2)` 保持现有索引并对已有图幅执行 `schemaRev = 2` 的回填迁移，用于演示后续结构升级路径。
- `version(3)` 引入按图幅提交的操作记录：升级时以现有全部记录为每个图幅生成 `seq = 0` 的基线提交（首个提交点），并建立提交记录、基线快照、待核与页签工作区四个仓库。

刷新或关闭页面不会丢失新增记录；浏览器站点数据被清除时会重新触发首次种子数据写入。

## 按图幅提交与并发协作

针对整理员常开两个页签处理同一图幅（一个改图幅与四至，另一个补扫描件和沿革）的场景，所有改动不再直接覆盖主档，而是走"暂存 → 按图幅提交"链路：

1. **写入先记操作记录**：改图幅、补扫描件、补地名、补沿革、切主用件都先在页签工作区暂存为可重放的操作步骤；提交按图幅聚合成一笔提交记录（`commits`），含序号、基序号、页签与步骤明细。
2. **两页签同时提交，保留双方步骤并重放**：后提交者从自己暂存时的基快照出发，先重放对方在基序号之后已提交的步骤，再合并自己的步骤。新增类改动（扫描件、地名、沿革）天然并存；图幅字段采用字段级比对。
3. **冲突内容进入待核，主档停在上一提交点**：双方改了同一字段时，该字段不写入主档，原步骤仍完整保留在提交记录中，并在 `pendingConflicts` 生成带「上一提交点 / 对方已提交 / 本页签想写入」三方值的待核条目，于「待核中心」人工采纳或舍弃；互不依赖的字段照常合并。
4. **写入失败从上一提交点恢复**：主档四仓、提交记录、待核、基线推进与工作区清理在同一个 Dexie 事务内完成，任何一步失败整体回滚，互相依赖的改动不会只落一半。「草稿与恢复」页可对任意图幅从上一提交点重放校准，并提供提交中途失败的故障演练开关。
5. **重开页签接着处理**：页签工作区以 `sessionStorage` 中的页签标识按 `[tabId, sheetId]` 持久化到 IndexedDB，刷新或重开本页签自动取回暂存步骤；其它页签遗留的草稿可在「草稿与恢复」页接管。页签间通过 `BroadcastChannel` 在提交后互相通知，各自回到上一提交点重载主档。
6. **旧数据升级**：`version(3)` 迁移把现有记录物化进每图幅基线快照与 `seq = 0` 基线提交，之后的第一笔真实改动即基于该提交点提交。

可执行 `npm run verify` 运行并发提交、待核、失败回滚、修复与旧数据升级的端到端断言脚本。

## 核心功能与路由表

| 路由 | 核心功能 |
| --- | --- |
| `/sheets` | 按年代、比例尺和状态筛选图幅，内联新建图幅，查看扫描件数、地名数、待提交/待核角标与邻接缺编提示 |
| `/sheets/:id` | 改图幅与四至（暂存）、扫描件登记与主用件切换、待提交步骤面板、按图幅提交、提交记录时间线与 JSON 导出 |
| `/places` | 古今地名双栏对照，按类型和确定度筛选，对古名、今名、异写及图上方位反向查询并高亮；新增先暂存 |
| `/places/:id/history` | 按年代排列沿革时间线，新增初置、改名、迁治或废置记录；新增先暂存并提示所属图幅待提交 |
| `/sheets/:id/neighbors` | 按四至排列邻接图幅，显示主用扫描件、缺编提示与拼合预览 |
| `/review` | 待核中心：查看字段级三方值，采纳或舍弃冲突，处置后从上一提交点重放校准 |
| `/drafts` | 草稿与恢复：续作本页签草稿、接管其它页签遗留草稿、放弃、按图幅提交、从上一提交点修复与故障演练 |
| `/`、未匹配路径 | 自动跳转到 `/sheets` |
